Privacy Policy — RocketPeach Pin Publisher

Last updated: 2026-11-01

RocketPeach Pin Publisher ("the app") is a personal, single-account tool used exclusively by the owner of the Etsy shop RocketPeach to publish Pinterest Pins promoting that shop's own product listings.

What the app does

  • Reads the operator's own Etsy shop listing data (title, tags, image, and listing URL) via the Etsy Open API.
  • Creates Pins on the operator's own Pinterest account, linking back to the corresponding Etsy listing, via the Pinterest API.
  • Lists the operator's own boards and Pins so that the same listing is not pinned twice.
  • Each Pin is individually selected and approved by the operator before it is published. The app does not publish content without the operator's specific review of that Pin.

What the app does not do

  • The app is used by a single individual for their own shop only. It is not distributed to, or used on behalf of, any other person, business, or Pinterest account.
  • The app does not access, read, collect, or store any data belonging to any other Pinterest user, board, or Pin.
  • The app does not share, sell, or transmit any data to third parties. Data obtained from the Etsy API and Pinterest API is used solely to create the operator's own Pins and is not retained beyond what is needed for that purpose.
  • The app does not use any data for advertising targeting, profiling, or any purpose outside of publishing the operator's own product Pins.

Data retention

Listing and Pin data used by the app is kept only on the operator's own computer and in the operator's own private storage, for as long as needed to operate the tool. It is never transmitted anywhere other than to the Etsy API and Pinterest API themselves.

Contact

Questions about this policy can be directed to the shop owner via the RocketPeach Etsy shop page: rocketpeach.etsy.com.
